# Gideon Steve B — Personal Portfolio

Responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — complete website.
- `README.md` — setup and GitHub Pages instructions.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish using GitHub Pages
1. Create a GitHub repository (for example, `gideon-steve-portfolio`).
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your website URL will appear in the Pages section.

## Before publishing
Ensure your Google Drive resume is shared with **Anyone with the link** so visitors can download it.
