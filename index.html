04 / SELECTED PROJECTS

PROJECT 01
ROBOTICS / ELECTRIC VEHICLES

Time-Efficient Automated EV Charging System

An intelligent robotic charging concept designed to automate the EV charging process. The system uses a three-axis robotic arm and a camera to identify a pre-registered QR code on a parked electric vehicle. After user authorization through a notification, the robotic arm initiates charging. The prototype integrates real-time alerts and GUI functionality to reduce human effort and improve the charging experience.

PROJECT 02
INTERNET OF THINGS / HOME AUTOMATION

Smart Socket System

An IoT-based smart socket that transforms an ordinary electrical socket into a Wi-Fi-controlled smart plug. The project uses an ESP8266, Arduino IDE, Blynk application and relay module. Users can control the connected socket through the application, demonstrating an approach to convenient home automation.
